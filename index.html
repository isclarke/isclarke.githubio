02 — SELECTED WORK

001

Unit Hub

IoT RASPBERRY PI FLASK REAL-TIME SENIOR CAPSTONE
↗

A full IoT laundry monitoring and reservation system for college dorms and apartments. Non-invasive current sensors attached to a Raspberry Pi detect washer/dryer states in real time — no appliance modifications required.

Users see live countdowns, reserve machines via a queue system, and receive SMS/email/in-app alerts. Admins get a management portal with cycle analytics and maintenance alerts. Built entirely from scratch as a senior design capstone.

KEY FEATURES

  • Real-time machine status with color-coded availability
  • Smart reservation queue with auto-cancellation
  • Multi-sensor fusion: temperature, humidity, vibration
  • Customizable notifications (SMS, email, in-app)
  • Admin portal for maintenance and analytics
  • Offline-capable local-first architecture
002

FANZ

SPORTS PLATFORM REST API REACT REAL-TIME DATA
↗

A multi-sport community platform delivering live scores, play-by-play stats, and event schedules across NFL, NBA, MLB, NHL, and soccer leagues. Built with a Flask backend consuming third-party sports APIs and a React frontend.

Features user profiles, favorite teams, membership tiers, direct messaging, and a community feed — all in a dark, information-dense interface optimized for extended browsing.

KEY FEATURES

  • Live scores & play-by-play for 5+ leagues
  • Inning-by-inning MLB game breakdowns
  • Personalized user profiles & favorite teams
  • Social feed, explore, and direct messaging
  • Upcoming events calendar across all leagues
  • RESTful API integration with sports data providers
003

Bur-View

MOBILE APP COMMUNITY MAPS GAMIFICATION
↗

A community engagement mobile app connecting Burlington residents with environmental activities — tree planting, cleanups, recycling — through gamified point systems and social features.

Users earn points redeemable at local partner businesses, join or create teams, and discover activities on an interactive real-time map. Designed with a warm earthy palette to reflect the environmental mission.

KEY FEATURES

  • Interactive real-time map of nearby activities
  • Solo & group activity modes with leaderboards
  • Points system redeemable at local businesses
  • Team management and group competition
  • Wearable device companion view
  • Scalable multi-city architecture
