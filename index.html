001

Laundry Room Usage Staus Monitoring Reservation System

IOTRASPBERRY PI FLASKREAL-TIME SENIOR CAPSTONE
↗

An IoT laundry monitoring and reservation system for college dorms and apartment complexes. Non-invasive current sensors on a Raspberry Pi detect washer and dryer states in real time — no appliance modifications required.

Users see live countdowns, reserve machines via a queue, and receive SMS, email, or in-app alerts. Admins get a full management portal with cycle analytics and early maintenance alerts based on vibration and sensor data.

KEY FEATURES

  • Color-coded real-time machine status dashboard
  • Smart queue-based reservation system
  • Multi-sensor data: temperature, humidity, vibration
  • Customizable alerts via SMS, email, and in-app
  • Admin portal for facility management
  • Local-first architecture with offline capability

SYSTEM SCREENS

Main Dashboard
Real-time view of all washers and dryers with color-coded availability (green = available, red = in use, orange = yours) and countdown timers
My Reservations
Scheduled bookings with machine ID, quad location, start time, and change or cancel options
Notification Settings
Granular control over delivery channels (in-app, email, SMS) and alert events (reservation ready, cycle ending, machine freed)
Report Issue
Machine issue submission with location filter, machine selector, issue type, and optional detail description
Messages
Direct communication channel between residents and facility admin
Profile
User settings: full name, email, phone number, location, and room number

Delicate Fit

A full-stack AI-powered fashion platform that enables users to virtually try on clothing using their own photos before purchasing. Built with a modern React frontend and Node/Express backend, the platform blends e-commerce with real-time AI visualization.

Designed with scalability and security in mind, the system implements JWT authentication, role-based admin controls, and a normalized SQL database handling products, users, orders, and AI-generated assets.

KEY FEATURES

  • Full e-commerce flow: browse, filter, cart, checkout
  • Admin dashboard for product & inventory management
  • JWT + bcrypt authentication with role-based access
  • REST API with protected Express middleware
  • Normalized SQL schema (users, products, orders, AI results)

APPLICATION SCREENS

Product Browsing & Filtering

Admin Product Management
